## Problems found

1. **Rigging from your reference images breaks the artwork.**
   - **What happens:** `rig_analyze.py` can't trace the legs of `taro_front.png` or `dino_stand.png`; the legs are close together or covered. It guesses 8 of 20 joints. When the caveman walks, the image tears, and during the wave, arm pieces fly off.
   - **Measured** (`verify.mjs`): planted feet 143 px off the ground, foot slide 30 px, joint pops of 66.9 rad/s, and a 236 px body jump.
   - **What the system intends instead:** cut-out puppet characters, made by `tools/action/puppet.py`. The character is redrawn in a mannequin pose with an image-edit model, so every joint is known.
2. **`tools/action/gen_character.mjs` does not exist.** `puppet.py` names it as the tool that runs the ComfyUI side of making a puppet character, but it was never committed. Today the puppet path needs manual steps:
   1. `puppet.py template`;
   2. redraw the mannequin as the character in ComfyUI;
   3. `puppet.py split`.
3. **Quadruped rigs crash the engine.**
   - **What happens:** `rig_analyze.py --template=quadruped` writes a rig that `src/action/composer.js` can't play. It looks for `thigh_f`, which quadruped rigs don't have, so the page never loads.
   - `tools/action/plan.mjs` accepts the plan anyway.
   - Your dinosaur stands on two legs, so the `human` template loads, but its legs aren't traced either (see problem 1).
4. **Collage films need artwork that hasn't been generated.**

   | Film | Missing files | Can it be generated? |
   |---|---|---|
   | `stone_friends` | 9 backgrounds and props (`bg_valley`, `bg_trail`, `bush`, …) | yes: prompts ready for ComfyUI |
   | `ww2_europe` | 14 files | yes: prompts ready for ComfyUI |
   | `collage_demo` | the `collage_reel` images | via `--story=collage_reel` |

   - **Before `86421e5`:** these rendered as blank, still frames, and nothing reported it.
   - **Now:** the run stops and lists the missing files.
5. **No narration voice.** The system has no text-to-speech. A film gets automatic SFX, plus music if you give it a file. A Thai voice must be recorded or generated outside, then passed in (`--narration=` in the audit).
6. **Minor issues:**

   - The studio page requests one file that returns 404.
